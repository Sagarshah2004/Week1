


# 🚀 React Week 1 Assignment

This project contains solutions to basic React tasks using **JSX, Components, Props, and State**.
It is built using **Create React App** and follows a clean component-based structure.

---

## 📌 Project Overview

The assignment includes the following tasks:

### ✅ Task 1: Personal Information

* Displays name, profession, and hobby using JSX.

### ✅ Task 2: Current Date & Time

* Shows current date and time.
* Includes dynamic version (live updating clock using React Hooks).

### ✅ Task 3: Dynamic Greeting

* Displays greeting message based on time (Morning/Afternoon/Evening).

### ✅ Task 4: List Rendering with map()

* Displays a list of articles using `map()` in JSX.
* Data rendered in table format.

### ✅ Task 5: User Card with Props

* Reusable component displaying user details (name, age, email).
* Demonstrates props usage.

### ✅ Task 6: Product List (Parent → Child)

* Parent component passes product data to child component.
* Demonstrates component communication and props.
